# Rock-Paper-Scissors Image Classification (Jupyter Notebook)

Deep learning term project (DAU500) that classifies hand images (rock, paper, scissors) using a pre-trained VGG16 model (transfer learning).

## What the notebook includes
- Data loading and augmentation
- VGG16 feature extraction and fine-tuning
- Model evaluation and accuracy graphs

## Tools
Python, TensorFlow/Keras, Matplotlib, Jupyter Notebook

## Files
- TermProjectDAU500RPS (1).ipynb: full notebook with code and results
